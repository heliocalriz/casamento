# **App Name**: GiftLink

## Core Features:

- Gift Display: Guests can view a list of all gifts, their availability status, and who has claimed them (if applicable).
- Gift Claiming: Users can select an available gift from the list and claim it by providing their name, marking it as unavailable.
- Availability Status Indicators: Each gift item will visually indicate whether it is 'Available' or 'Claimed' to enhance user experience.
- Admin Gift Management: A secured section for the host to add new gifts, edit existing gift details, or remove gifts from the list.
- AI Gift Description Tool: For administrators, an AI tool that suggests creative and compelling descriptions for new gift items based on minimal input.

## Style Guidelines:

- The visual design will employ a light color scheme to evoke a celebratory and warm atmosphere.
- Primary color: A sophisticated deep rose (#AA2D6E), representing thoughtfulness and elegance.
- Background color: A very light, desaturated rose (#F9EDF4) to maintain continuity with the primary hue while keeping the interface bright and airy.
- Accent color: A rich plum (#7F1A66), analogous to the primary, providing a complementary darker tone for highlights and interactive elements.
- Headline font: 'Playfair', a modern serif for a fashionable and elegant appeal in titles and headings.
- Body font: 'PT Sans', a humanist sans-serif, will provide clear readability and a touch of warmth for all descriptive text.
- Utilize simple, elegant line-art icons that complement the celebratory theme without being overly ornate.
- A clean, card-based layout for gift items, ensuring easy browsing and a focus on the gift details.
- Subtle and tasteful animations for user interactions, such as claiming a gift or navigating between sections, enhancing the user experience without distraction.
